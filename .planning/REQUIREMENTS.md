# Project Requirements: CareerCompass v2.0

## 1. AI Mentor Persona Selection (PERSONA)
- [ ] **PERSONA-01:** Allow users to choose from specialized AI Advisor Personas (e.g., "Tech Specialist", "Empathetic Academic Advisor", "Strict Career Coach").
- [ ] **PERSONA-02:** Custom system prompts tailored to each selected persona influencing response style and tone.

## 2. Real-time Streaming AI Chat (STREAM)
- [ ] **STREAM-01:** Implement streaming AI text generation for responsive, sub-second latency chat feedback.
- [ ] **STREAM-02:** Dynamic typing indicators and markdown message rendering with rich code/list formatting.

## 3. Voice Interaction & Accessibility (VOICE)
- [ ] **VOICE-01:** Voice input using Web Speech API / speech recognition for hands-free queries.
- [ ] **VOICE-02:** Text-to-speech audio readout for advisor responses with toggleable sound controls.

## 4. Extended Memory & Context Integration (MEM)
- [ ] **MEM-01:** Inject user profile context (current grade, field of interest, target country, saved colleges) into AI chat session context.
- [ ] **MEM-02:** Persistent multi-conversation history management with thread renaming and deletion.
