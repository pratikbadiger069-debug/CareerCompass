## Milestone v2.0: AI Mentor Chatbot Enhancements

### Phase 6: AI Mentor Persona Selector & System Prompt Engine
- **Objective:** Build persona selection UI and backend system prompt dispatch.
- **Deliverables:**
  - Persona selector modal / component (Tech Specialist, Empathetic Advisor, Strict Coach).
  - Backend system prompt decorator based on selected persona.

### Phase 7: Real-time Streaming Chat & Enhanced Markdown Rendering
- **Objective:** Deliver sub-second streaming AI responses and rich formatting.
- **Deliverables:**
  - Server-sent events / streaming chat endpoint.
  - Streaming text UI with typing indicator and formatted markdown cards.

### Phase 8: Voice Input & Text-to-Speech Accessibility
- **Objective:** Add hands-free speech recognition and audio playback.
- **Deliverables:**
  - Speech-to-text mic input button with real-time transcript.
  - Text-to-speech audio reader with voice selection and volume controls.
